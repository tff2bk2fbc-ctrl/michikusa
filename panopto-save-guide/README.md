# Panopto 保存ガイド

正当にアクセス権を持ち、動画の提供者からダウンロードを許可されている利用者を、Panoptoの公式な保存手順へ案内する小規模なGitHub Pagesアプリです。

## できること

- `*.panopto.com` の共有URL（Viewer、Embed、Sessions）を検証する
- 確認済みの共有URLをPanopto公式ページで開く
- Panoptoの公式画面から利用者自身が取得した、同一サイトのダウンロードURLを確認し、「動画をダウンロード」リンクを表示する
- すべての入力をブラウザ内だけで処理する

## しないこと

- 認証、アクセス制御、DRM、ダウンロード禁止設定を回避する
- ページや通信を解析して非公開の動画URLを抽出する
- Cookie、認証情報、動画データを収集・中継・保存する
- ダウンロード項目が表示されない動画を取得可能にする

ダウンロード項目がPanoptoの公式画面に表示されない場合は、その場で終了し、動画の所有者または所属組織の管理者へ確認してください。

## ファイル構成

```text
.
├── index.html   # 画面と説明
├── styles.css   # レスポンシブ表示、ライト・ダーク・高コントラスト対応
├── app.js       # URL検証と公式ページを開く処理
└── README.md
```

外部ライブラリ、ビルド処理、バックエンドはありません。

## ローカルで確認する

Python 3がある場合、リポジトリのフォルダで次を実行します。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。ファイルを直接開いても基本機能は動作します。

## GitHub Pagesで公開する

1. このファイル一式をGitHubリポジトリの既定ブランチへ追加します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** のSourceで **Deploy from a branch** を選びます。
4. 対象ブランチと `/ (root)` を選び、保存します。
5. GitHubが表示する公開URLを開きます。

公開サイトにURLや認証情報を保存する仕組みはありません。GitHub Pagesは静的ホスティングのため、Panoptoの認証済みコンテンツを代理取得することもありません。

## URL検証の方針

共有URLはHTTPSかつ `*.panopto.com` の既知の共有パスだけを許可します。公式ダウンロードURLは、入力済み共有URLと同じホストに限定します。これは任意サイトへの誘導や、無関係な配信元のURLを扱うことを避けるためです。

組織が `panopto.com` 以外の独自ホスト名を正式に使用している場合は、運用者が組織の管理者に確認したうえで、`app.js` の `isPanoptoShareUrl` を明示的な許可リスト方式で変更してください。ワイルドカードで任意ホストを許可しないでください。

## 利用上の注意

このプロジェクトはPanoptoの非公式ツールです。Panopto、所属組織、授業または動画の提供者が定める規約、著作権、保存期間、再配布禁止などの条件に従ってください。保存が許可されていても、第三者への共有が許可されているとは限りません。
